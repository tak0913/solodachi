アプリがなくても使える知識 music basics
キーって何? key

曲の「ホーム」になる音のこと。キーがCなら、C(ド)に戻ってくると「終わった」感じがする。キーが決まると、使うと気持ちいい音のセットも決まる。

スケールって何? scale

キーの中で使う音のセット。メジャースケールは明るく、マイナースケールは切なく聞こえる。全部覚えなくていい。まずは「光ってる形」を指で覚えるところから。

コードの音(コードトーン)って? chord tone

コードは音を重ねたもの。たとえばCは C・E・G(ド・ミ・ソ)。伴奏がこの音を鳴らしてるから、同じ音を弾くと絶対ぶつからない。フレーズの「着地点」にすると安定する。

パワーコードって?(メタル)power chord

ルートと5度(ルートから数えて5番目の音)の2音だけのコード。明るい/暗いを決める3度の音がないから、強く歪ませても音がにごらない。だからロックやメタルの定番。

ペンタトニックとブルーノートって?(ブルース)pentatonic / blue note

ペンタトニックは5つの音だけのスケールで、どこを弾いても外れにくい。そこに「ブルーノート」(わざと少し外した切ない音)を足したのがブルーススケール。明るいコードの上で暗めの音を弾く、そのぶつかりがブルースの味。

7thコードとadd9って?(ヒップホップ・シューゲイザー)seventh chord / add9

7thコードは3つの音にもう1つ足した4音のコードで、おしゃれで大人っぽく聞こえる。add9は「9番目の音」(ルートの1つ上の音を高くしたもの)を足したコードで、ふわっと浮いた感じになる。

ドリアン・ミクソリディアン・フリジアンって? modes

メジャーやマイナーの音を1つだけ変えた「親戚」のスケール。ドリアンはマイナーの1音を明るくして「切ないけどおしゃれ」に(ヒップホップやファンク)。ミクソリディアンはメジャーの1音を下げて「明るいけどゆるい」感じに(ロック)。フリジアンはマイナーの2番目の音を下げて「暗くて不気味」に(メタル)。その1音が、コードボタンの「決め手」って書いてあるやつだよ。

拍子と変拍子って? time signature / odd time

拍子は「1小節に何拍あるか」。4/4拍子は「ワン・ツー・スリー・フォー」で、ほとんどの曲がこれ。3/4拍子は「ズン・チャッ・チャッ」のワルツ。6/8拍子は「タッタタ・タッタタ」と揺れるノリでバラードに多い。5/4や7/8みたいに数えにくい拍子を「変拍子」と呼ぶこともあるし、曲の途中で拍子が変わることも変拍子と言う。アニソンや邦ロックでは「1小節だけ3拍を差し込む」みたいに、聞く人をドキッとさせる仕掛けとして使われることが多い。コードをタップして拍子を変えると、自分でも作れるよ。

シャッフル・跳ねるリズムって? shuffle / swing

「タッタ、タッタ」と前の音を長く、後ろの音を短くするノリ。ブルースは大きく跳ねて、ヒップホップは少しだけ跳ねる。同じフレーズでも、跳ねるだけでジャンルの空気が変わる。

トレンドパックって? trend pack

お手本の中で【トレンド】がついてるのが、今のヒット曲でよく使われる進行。たとえば4156進行(IV→I→V→vi)は、米津玄師「Lemon」のサビなどで使われてる。王道進行・改や丸サ進行には、キーの外から借りた「スパイス」のコードが入ってて、ちょっと大人っぽくて切ない響きになる。コード進行そのものには権利がないから、自分の曲に自由に使っていいよ。

I とか vi って何の記号? Roman numerals

キーの中で何番目の音から作ったコードかを表す番号(ディグリー)。大文字は明るいコード、小文字は暗いコード。番号で覚えると、キーが変わっても同じ進行をそのまま使える。

日本と海外の言葉の違い Japanese vs English terms

音楽用語には、日本でしか通じない言い方(和製英語)がけっこうある。海外の動画やDAWを使うときのために、セットで覚えておこう。
・8ビート/16ビート → straight eighths / sixteenths, rock beat(英語圏では「8ビート」とはあまり言わない)
・サビ / Aメロ / Bメロ / Cメロ → chorus / verse / pre-chorus / bridge
・チョーキング → bend(弦を押し上げて音程を上げる)
・ブリッジミュート → palm muting
・カッティング → funk strumming / muted strumming
・シールド → cable(イギリスでは lead)
・エフェクター → pedal / effects
・耳コピ → learning by ear / transcribing
・4156進行・小室進行 → 日本独自の呼び名。海外では IV–I–V–vi のように番号で言う
・王道進行 → Royal Road progression、丸サ進行 → Just the Two of Us progression と呼ばれることがある

補助輪はどう外す? removing the training wheels

Lv1で光る形を眺める → Lv2でコードの音だけ狙う → Lv3でルートを頼りに耳で探す → Lv4で何も見ずに弾いて、答え合わせだけする。Lv4で◎がたくさん出るなら、もう補助輪はいらないかも。
